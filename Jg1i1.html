문제

사용자가 입력한 두 이름이 같은 성인지 다른 성인지 판단하는 문제입니다 이를 해결하는 프로그램을 작성하세요 
A님, 이름을 입력하세요: 허난설헌
B님, 이름을 입력하세요: 허균
허난설헌과 허균은 성이 같습니다. 


A님, 이름을 입력하세요: 신사임당
B님, 이름을 입력하세요: 왕건
신사임당과 왕건은 성이 다릅니다. 


A님, 이름을 입력하세요: 김만덕
B님, 이름을 입력하세요: 김유신
김만덕과 김유신은 성이 같습니다.

알고리즘 설계

프로그램 시작 
   이름 2개를 입력 
   첫음절이 같으면 성이 같습니다. 출력 
   첫음절이 다르면 성이 다릅니다. 출력 
프로그램 종료

프로그램 구현

     
  
 ※ 단계별 점검: A키(이전), D키(다음)

3			String nameB = scan.next();

4			if ( nameA.charAt(0) == nameB.charAt(0) )

6			else

7				System.out.print( nameA + "과 " + nameB + "은 성이 다릅니다. " );
